    📖 Методика расчёта

    1. Двигатель. Номинальный момент Mном = 9549·Ne/n1 (Н·м). Без таблицы — парабола с пиком 1.15·Mном при 0.7·n1; с таблицей — интерполяция PCHIP (Fritsch–Carlson) по точкам ВШХ, за границами таблицы — кламп к крайним точкам. Педаль α масштабирует располагаемый момент.

    M_дв(n) = α·[ M_пик − k·(n − n_пик)² ]

    2. Нагрузочная парабола ГТР.

    M_нагр(i, n) = λ(i)·C_n·n² C_n = ρ·(π/30)²·D⁵ λ(i) = λ₁·(1 + 0.4·(1 − i)²), λ₁ = M_ном / (C_n·n₁²)

    3. Рабочая точка — пересечение нагрузочной параболы и располагаемого момента двигателя: сканирование по сетке + бисекция, берётся устойчивый корень (нагрузка пересекает характеристику двигателя снизу). Холостые обороты — 800 об/мин.

    4. Коэффициент трансформации K₀ — по геометрии проточной части:

    K₀ = 1 + 0.5485·(|cot β_T2|·r_T2/r_H2 + |cot β_P2|·r_P2/r_H2)

    Расширенная модель: поправка Пфлейдерера–Стодолы на конечное число лопаток — коэффициент μ считается по каждому сечению, в K₀ входит среднее геометрическое по шести сечениям.

    5. Точка сцепления — реактор освобождается, трансформация момента прекращается:

    i_coup = clamp( 1 − 0.15·(K₀ − 1)/1.35 , 0.5 … 0.98 )

    6. Кривая K(i) с учётом ударных потерь ξ от рассогласования углов лопаток:

    ξ₀ = φ·(Δβ²_н + Δβ²_т + Δβ²_р)/3 ξ(i) = ξ₀·(1 − i/i_coup) K₀эфф = max(1, K₀·(1 − 0.5·ξ(i))) K(i) = K₀эфф − (K₀эфф − 1)·(i/i_coup)^0.7 при i < i_coup K = 1 при i ≥ i_coup

    7. Расход Q — из уравнения моментов Эйлера для контура циркуляции (квадратное уравнение относительно Q).

    8. Потери трения в круге циркуляции:

    Re = v·D_h/ν λ_эфф = max( λ_tr·(10⁴/Re)^0.25 ; 64/Re ) h_тр = λ_эфф·(L/D_h)·v²/(2g), L = πD, D_h = 2b η_тр = P_тр/N_нас (ограничение ≤ 0.9)

    9. КПД и энергобаланс — замкнут: N_турб + Q_тепла = N_нас в каждой точке сетки (проверяется юнит-тестами):

    η = K·i·η_мех·(1 − η_тр) при i < i_coup η = i·η_мех·(1 − η_тр) при i ≥ i_coup N_турб = η·N_нас ⇔ M_турб = η·M_нас / i η_сист = (N_турб − 0.5 кВт) / N_нас Q_тепла = N_нас − N_турб

    10. Блокировка (lock-up). Заданная точка блокировки автоподнимается до точки сцепления, если была ниже. При i ≥ i_lock фрикцион замкнут: K = 1, η = η_мех, циркуляция Q = 0, жидкость не греется (T = T₀). В полосе шириной 0.04 перед i_lock фрикцион подхватывает момент пропорционально — плавный переход без скачка.

    11. Термомодель жидкости. Равновесная температура из теплового баланса, свойства жидкости зависят от T (итерации до сходимости):

    T = T₀ + Q_тепла·1000 / K_охл ν(T) — уравнение Уолтера (ASTM D341), нормировка на ν при T₀, опорные точки ATF: 40 °C → 35 сСт, 100 °C → 7.5 сСт ρ(T) = ρ·(1 − 0.0007·(T − T₀))

    Источники: уравнения Эйлера для турбомашины; эмпирические зависимости по С.П. Стесин «Гидродинамические передачи», Машиностроение, 1973/1990; температурная зависимость вязкости — ASTM D341.
